# FlowCortex

FlowCortex is a **payment-centric, ordering-less blockchain** built in Rust.

### Core Ideas
- Ordering-less execution
- ProofCortex + QCT finality
- WASM-based runtime
- Zero-knowledge proofs
- Post-quantum cryptography
- CPU / GPU / ASIC optimized verification
